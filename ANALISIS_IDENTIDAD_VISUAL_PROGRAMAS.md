## 📐 Elementos de Diseño Comunes

### Estructura Visual:
1. **Fondo superior ondulado**: Diseño "wavy" en marrón/rojo
2. **Área de contenido**: Fondo color (blanco, pastel, etc.)
3. **Foto de presentadores**: Lado derecho, tamaño prominente
4. **Información textual**: Lado izquierdo, limpio y legible
5. **Logo del programa**: Integrado en diseño, lado derecho o arriba

### Tipografía:
- **Títulos**: Bold, sans-serif moderna
- **Subtítulos/Horarios**: Bold, más pequeño
- **Descripción**: Regular, legible
- **Tamaño**: Jerarquía clara (grande → medio → pequeño)

### Fotografía:
- Presentadores profesionales
- Fotos dinámicas, con personalidad
- Bien iluminadas
- Composición que destaca rostros
- A veces con props o elementos temáticos

### Iconografía:
- Logos distintivos por programa
- Símbolos relacionados a tema (ramen, micrófono, cámara, dados)
- Estilo moderno, minimalista
- Colores vibrantes

## 💡 Características de Identidad Coherente

1. **Consistencia de Layout**: Todos los programas siguen estructura similar
2. **Variación de Colores**: Cada programa tiene color distintivo
3. **Elementos Recurrentes**: Logo, horario, talentos, descripción
4. **Fondos Ondulados**: Elemento visual recurrente de marca
5. **Foto Prominente**: Presentadores siempre visibles
6. **Información Clara**: Horarios, públicos, descripción consistentes

---

## 🎯 Recomendaciones para Implementación Web

### Para la App Ninja House:

1. **Colores Primarios**: Usar el rojo vibrante como color principal de marca
2. **Fondos Pastel**: Rosa pastel para secciones de contenido
3. **Tarjetas de Programas**: 
   - Logo del programa
   - Foto pequeña de presentadores
   - Horario destacado
   - Descripción breve
   - Color distintivo por programa
4. **Tipografía**: Sans-serif bold para títulos, regular para contenido
5. **Elementos Ondulados**: Decoración "wavy" en bordes de secciones
6. **Paleta de Acentos**: Usar los colores secundarios de cada programa como acentos

Ninja House tiene una identidad visual **moderna, colorida y juvenil** que respeta la marca madre mientras permite variación creativa por programa. La consistencia en estructura con variación en colores crea un balance entre cohesión y diversidad.
