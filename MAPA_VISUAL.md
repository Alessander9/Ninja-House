## 📱 Responsive Breakpoints

```
Móvil (320-640px):     1 columna de cards
Tablet (641-1024px):   2 columnas de cards
Desktop (1025px+):     3 columnas de cards
```

## ✨ Elementos Decorativos

### Wavy Top Decoration
```
Presente en cada card, onda superior
Color: Color primario del programa
Altura: ~12px
Efecto: Separa visualmente el contenido
```

### Spacing
```
Padding interior:      16px (md)
Margin entre cards:    24px (lg)
Section padding:       32-48px (xl)
```
